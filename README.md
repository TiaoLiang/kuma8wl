# 熊八的武林

一百二十公斤的上班族熊八，公司尾牙抽中武俠溫泉，結果滑進了武俠世界，還一屁股坐垮了武林大會的盟主寶座……

武俠卡牌 RPG：起手→承接→收勢的連招、剛快柔奇的架勢相剋、七大門派、二十位夥伴、五卷劇情、宗門經營、懸賞、秘境、輪迴二週目。

**▶ 線上遊玩：https://tiaoliang.github.io/kuma8wl/**

- 電腦、手機瀏覽器都能玩，不用安裝。
- 存檔存在你自己的瀏覽器；換裝置可以用遊戲選單裡的「存檔碼」搬存檔。
